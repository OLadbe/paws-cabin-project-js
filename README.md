# :feet: Проєкт "Хатинка Лапок" — Притулок для тварин

Адаптивний вебсайт для притулку тварин, створений командою розробників у межах командного JavaScript-проєкту. Сайт допомагає користувачам знайти чотирилапого друга, ознайомитися з діяльністю притулку, прочитати успішні історії адаптації та залишити заявку на знайомство з тваринкою.

---

## :hammer_and_wrench: Технологічний стек

* **HTML5** — семантична верстка, розділена на незалежні HTML-partials
* **CSS3** — методологія BEM (Block Element Modifier), кастомні CSS-змінні (Variables), адаптивна та гумова верстка (Mobile First)
* **JavaScript (ES6+)** — асинхронні запити, динамічний рендеринг DOM, робота з API
* **Axios** — HTTP-клієнт для взаємодії з бекендом
* **SweetAlert2** — красиві кастомні модальні вікна сповіщень та валідації
* **Vite** — інструмент для швидкої збірки та деплою проєкту

## :clipboard: Основний функціонал проєкту

1. **Глобальний локальний лоадер** — інтегрований у секцію каталогу тварин (`Наші хвостики`), що покращує UX під час отримання даних.
2. **Динамічний каталог з API** — завантаження карток тварин у реальному часі за категоріями, реалізовано пагінацію (кнопка "Показати ще").
3. **Фронтенд-валідація форм** — сувора перевірка полів "Ім'я" та "Телефон" (регулярні вирази) до моменту відправки запиту на бекенд.
4. **Адаптивне мобільне меню** — контент обмежений безпечним контейнером на будь-яких дозволах екрана, реалізовано плавний якірний скрол (`scroll-behavior: smooth`).
5. **Повна відповідність макету Figma** — витримані стани `hover`/`focus`/`active` для кнопок, навігації, категоріальних фільтрів та іконок соціальних мереж.
